# EasyLife — نظرة عامة

## الرؤية
نظام موحّد يجمع **محاسبة متكاملة (قيد مزدوج)** و**متجراً إلكترونياً** على قاعدة بيانات واحدة. كل حدث تشغيلي (طلبية، استلام بضاعة، دفعة، جرد) يولّد **تلقائياً** حركة مخزون وقيداً محاسبياً، فلا يوجد إدخال مزدوج ولا تضارب بين المتجر والدفاتر.

## النطاق
**ضمن النطاق (Backend):**
- إدارة المنتجات والمخزون: إضافة، تعديل، أرشفة، حذف (محمي)، تعطيل ظهور المنتج للزبائن، متغيّرات، مخازن، حركات، جرد، تحويل.
- إدارة الطلبيات: من المتجر أو يدوياً، حالات، حجز مخزون، فواتير، دفعات، مرتجعات.
- المحاسبة: شجرة حسابات، قيود يومية، فترات مالية، ضرائب، **متعدد العملات**، تقارير.
- المشتريات: موردون، أوامر شراء، استلام، ذمم دائنة.
- API إداري + API عام للمتجر (Storefront).

**خارج النطاق حالياً:** واجهات المستخدم (لوحة الإدارة وواجهة المتجر)، بوابات الدفع، شركات الشحن، الرواتب، الأصول الثابتة، Multi-tenant (التصميم يسمح بإضافة `company_id` لاحقاً).

## القرارات المعتمدة
| البند | القرار |
|---|---|
| الإطار | Django 5.2 + Django REST Framework |
| قاعدة البيانات | PostgreSQL |
| المهام الخلفية | Management commands + cron (انتهاء الحجوزات، تقارير) |
| المصادقة | JWT (simplejwt) |
| المحاسبة | قيد مزدوج كامل |
| العملات | متعدد العملات من البداية (عملة أساسية + عملات معاملات) |
| الشركات | شركة واحدة |

## أنواع المستخدمين والصلاحيات
ثلاثة أنواع، والتحكم بصلاحيات الموظفين **ديناميكي يحدده الأدمن من لوحة الإدارة**:

| النوع | `user_type` | الوصول |
|---|---|---|
| **زبون** | `customer` | Storefront فقط: كتالوج، سلة، طلباته، عناوينه. لا يدخل الإدارة أبداً |
| **موظف** | `staff` | لوحة الإدارة، **بالصلاحيات التي يمنحها له الأدمن فقط** (لا صلاحية افتراضية) |
| **أدمن** | `staff` + `is_superadmin` | كل الصلاحيات + إدارة المستخدمين والأدوار والصلاحيات |

**كيف تُمنح الصلاحيات للموظف:**
1. **أدوار (Roles):** مجموعات صلاحيات يُنشئها الأدمن ويعدّلها (مثل «محاسب»، «أمين مخزن»، «مبيعات»، أو أي دور جديد). القوالب الجاهزة تُزرع كبداية فقط ويمكن تعديلها.
2. **صلاحيات مباشرة للموظف (Overrides):** إضافة صلاحية أو **سحبها** من موظف معيّن بعينه فوق دوره (الصريح `deny` يتغلب على الدور).
3. **نطاق الصلاحية (Scope) اختياري:** تقييد الموظف بمخزن معيّن، أو بحد أقصى لمبلغ (مثل خصم حتى 10%، أو تعديل مخزون حتى كمية معيّنة).
4. صلاحيات فعلية = (صلاحيات أدواره) + (الإضافات المباشرة) − (المسحوبات المباشرة)، ويُتحقق منها في الخادم عند كل طلب.

تفاصيل الصلاحيات (الكتالوج الكامل لرموز الصلاحيات) في [02-database-design](02-database-design.md) و[06-security](06-security.md).

## مصطلحات
- **Product**: المنتج المعروض (مثل «قميص»). **Variant**: الوحدة القابلة للبيع/التخزين (قميص-أزرق-L) ولها SKU.
- **On hand**: الكمية الفعلية. **Reserved**: محجوزة لطلبيات. **Available** = on_hand − reserved.
- **Base currency**: عملة الدفاتر. **Transaction currency**: عملة المستند.
- **Posting**: ترحيل القيد (يصبح نهائياً ولا يُعدَّل، يُعكس بقيد معاكس).
- **Append-only**: سجل لا يُعدَّل ولا يُحذف (حركات المخزون، القيود المرحّلة).
